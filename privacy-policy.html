ClassTrail

Privacy Policy

Chrome Extension for the Genesis Student Portal

Effective Date: November 8, 2026  ·  Version 1.4

Short version: ClassTrail has no ClassTrail-operated backend. It reads academic information from supported Genesis pages and stores it in Chrome's local extension storage. The extension does not read or store student names, teacher names, or portal page URLs. The optional AI Advisor can run a downloaded WebGPU model on-device, or send messages and relevant academic context to a remote provider you configure. ClassTrail sends limited feature-usage events to Umami Cloud; event payloads exclude student names, teacher names, grades, portal URLs, API keys, and chat contents, but Umami receives request metadata such as your IP address. Initial model downloads contact model-artifact hosts without student data.

1. Overview & Audience

ClassTrail ("the extension", "we", "our") is a Chrome browser extension for middle and high school students. It reads academic information from supported Genesis Student Portal pages, displays it in a side panel dashboard, and offers an optional AI Advisor that can use a local WebGPU model or a remote provider configured by the user.

The extension has no ClassTrail-operated backend. It processes academic information in the browser and sends limited feature-usage events to Umami Cloud. AI messages and relevant academic context are sent to a third-party AI provider only when a user configures and uses remote AI. Students under 13 may use the extension. This policy describes the extension's current technical behavior; it is not a determination that the product complies with COPPA or other laws.

For parents and guardians: Academic records are stored locally by Chrome; the extension does not read or store student names, teacher names, or portal page URLs. In local-model mode, advisor prompts and responses stay on the device after the model is downloaded. In remote-provider mode, the Advisor sends the student's message and conversation history to the selected provider, and adds grade data only when a question asks about the student's own academic progress. A student could type identifying information into a message, and previous conversation messages are sent with later remote requests. Matching Edison reference summaries are included for relevant questions. Umami Cloud receives limited feature events and normal request metadata such as the IP address. There is no built-in parent/guardian consent check; review the providers' terms and policies before use.

2. Data the Extension Reads

When a supported Genesis page is open, the extension's content scripts automatically inspect the page and may read:

  • Course names and grade averages per marking period (teacher names are not read)
  • Assignment details: names, scores, missing or upcoming status
  • Attendance summary (present, absent, tardy counts)
  • A parse timestamp (the portal page URL is not stored)

Parsing happens in your browser. The extension does not inspect or store the student's name or teacher names, and it does not store the portal page URL because URLs may contain student identifiers. On grade pages, the extension may automatically switch through marking-period selections to gather available grade history, then restore the original selection. The extension has no ClassTrail-operated server, but some academic information is sent to third parties as described in Section 4. The portal approval setting is not a guaranteed technical barrier against content-script parsing on every matched page.

3. How Data Is Stored

Parsed academic data (excluding student and teacher names and portal page URLs), settings (including the AI API key), and conversation history are stored in chrome.storage.local, a local extension storage area managed by Chrome. On upgrade, the extension removes previously saved student-name, teacher-name, and portal-URL fields. This storage:

  • Is stored in the local Chrome profile and is not Chrome Sync storage
  • Is separated from ordinary website storage; it is not an encrypted vault
  • Remains until you use the extension's Reset control, clear extension data, or uninstall the extension
  • Retains up to the latest 50 AI conversation messages; academic data has no automatic expiration
  • Downloaded local model artifacts are cached by the browser and can be deleted from Settings

4. AI Provider & API Calls

The AI Advisor is optional. Local WebGPU inference requires no API key and runs in an extension offscreen document. Remote AI providers require a configured API key. There is no ClassTrail server in either request path.

What is sent to the AI provider

In remote-provider mode, each Advisor request includes:

  • The message you just entered and prior conversation messages (up to 50 are stored locally; stored conversation history is included with each request and may contain information the student typed)
  • Student-specific course names/grades, average, GPA, missing-assignment count, and attendance summary only when the current question explicitly asks about the student's own academic progress. The extension does not intentionally add the parsed student name to the system prompt.
  • When the question matches a supported Edison topic, a relevant summary of public placement/curriculum documents bundled with the extension, including the official source URL
  • Your API key, as required to authenticate with the provider

In local-model mode, the same relevant prompt/context is passed to the on-device model and is not sent to an AI provider. The first model download retrieves model artifacts from configured hosting services and contains no student data. The extension does not make a separate request to Edison to retrieve bundled summaries. The connection-test feature uses a generic test prompt and does not include the stored student record or conversation history.

Who receives this data

Remote-provider prompts are sent to the endpoint configured in Settings. Depending on your selection, the recipient may be:

  • Anthropic (api.anthropic.com) — Anthropic Privacy Policy
  • OpenAI (api.openai.com) — OpenAI Privacy Policy
  • Microsoft Azure OpenAI (*.openai.azure.com) — Microsoft Privacy Statement
  • Google Gemini (generativelanguage.googleapis.com) — Google Privacy Policy
  • OpenRouter (openrouter.ai) — OpenRouter Privacy Policy
  • A custom OpenAI-compatible endpoint you provide, which may be operated by another organization

For local model downloads only, the extension contacts Hugging Face and related model-artifact hosting domains to retrieve model files. These requests do not include prompts, grades, conversation history, or API keys. After the model is cached, inference runs on-device.

These providers receive student information directly and may process or retain it under their own terms and policies. ClassTrail does not control their handling of data. Review the recipient's privacy, data-retention, and age-related terms before configuring it, and do not send student information to an endpoint you do not trust.

API keys

Remote-provider API keys are stored in chrome.storage.local and sent to the configured AI endpoint to authenticate remote requests. Gemini requests include the key in the request URL. Local inference does not require or send an API key. Do not use a key you are not authorized to use, and remove it by resetting the extension or clearing its stored data.

Feature-usage analytics

ClassTrail sends limited feature events to Umami Cloud (cloud.umami.is). Event payloads include event names and limited metadata such as course counts or selected AI provider type; they do not include student names, teacher names, grade values, course names, portal URLs, API keys, or chat contents. Umami receives normal request connection metadata, including the IP address, and processes requests under its own policies. See Umami's privacy policy.

Events include grades_parsed (course and marking-period counts), advisor_message_sent (provider type), ai_connection_tested (provider type), and conversation_cleared (no event metadata).

6. Children's Privacy (COPPA)

ClassTrail is intended for middle and high school students, and students under 13 may use it. The extension reads and stores academic records locally, but does not read or store student names, teacher names, or portal page URLs. Its optional AI feature can process messages and relevant context on-device, or send messages and conversation history to the provider configured by the user. Limited feature events are sent to Umami Cloud as described above.

The extension has no account system and no built-in age gate or parent/guardian consent verification. A user-configured API key is not proof of parental consent. Parents and guardians should review this policy and the relevant third-party terms before enabling AI or allowing a student to use the extension. This policy is not a legal compliance certification.

ClassTrail operates no server-side student record store. This does not prevent third-party providers from receiving or processing information as described above.

Parents or guardians with questions may contact us using the information in Section 10. To remove locally stored extension data, use the Reset control in Settings or uninstall the extension. Data already sent to third parties is subject to those providers' policies and deletion processes.

7. Data Sharing & Sale

ClassTrail does not operate a backend that receives student records. In local-model mode, advisor inference occurs on-device, although downloading model artifacts contacts their hosting services without sending student data. In remote-provider mode, AI request data goes to the configured provider. Limited feature events are sent to Umami Cloud. We do not sell student data. Each third party handles the information it receives under its own policies and terms.

8. Security

Security measures built into the extension:

  • All AI responses are text-escaped before display — no raw HTML from AI is ever injected into the page (XSS prevention)
  • API keys are stored in Chrome's local extension storage and are not exposed through ordinary website storage
  • Remote AI calls and local model inference run in extension-owned contexts, separate from the portal page's JavaScript context
  • No external scripts, fonts, or resources are loaded from third parties

Local extension storage is not an encrypted vault. Third-party AI, model-artifact, and analytics services receive network requests as described in Section 4.

9. Changes to This Policy

If this policy changes, we will update the Effective Date above and publish the new version in the Chrome Web Store listing. Continued use of the extension after changes constitutes acceptance of the updated policy.
